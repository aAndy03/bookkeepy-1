design system v1.7.1
updated 2026-10-19 · see CHANGELOG
bookkeepy · atoms 01
Button, Link, Icon, Label, Kbd.
Each atom starts from gpui-kit’s behaviour API (base primitive when one exists, otherwise the styled component’s builders) and lists every state that API can produce. We style all of them with our tokens. Masters are pen.dev components; the matrices are instances with overrides.
