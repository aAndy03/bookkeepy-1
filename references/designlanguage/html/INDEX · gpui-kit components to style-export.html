What we style, in atomic order.
Every gpui-kit 0.8 piece, sorted into atoms, molecules, organisms and system layers. Where a behaviour-only base primitive exists we style the base and keep its behaviour; where only a styled component exists we restyle it with our tokens. Priority follows the shell and the first screens (overview, transactions, accounts). Skipped pieces are kept visible so the list stays complete.
Source: gpui-kit.com/base and /versions/main/component (main docs; check each against the 0.8.0 crate before styling).
