bookkeepy · our own components
Our own components.
The parts gpui-kit doesn’t have: money and time atoms, the shell’s small molecules and the board’s HUD parts. Same rules as the kit: masters are pen.dev components, states are theme axes. Axes introduced here: money, privacy, day, sync, place.
C1
Amount
bookkeepy custom atom
component v1.2.0
what it is
Sign, digits and currency as one unbreakable unit. Digits use Inter tabular figures so columns align; the currency is a size and a tone smaller. Direction is a theme axis, so a table row only says money: in and the color and sign follow. Hiding amounts is a second axis (privacy) that swaps digits for bullets everywhere at once.

caption, muted; never wraps away from the digits
